Esta extensão oferece proteções de ponta, feitas para máxima privacidade e usabilidade. Funciona na hora: zero configuração necessária!

PROTEÇÕES PRINCIPAIS

• Bloquear anúncios e rastreadores: Impede o carregamento de anúncios invasivos, scripts de rastreamento e pixels no navegador.
• Resistência avançada a fingerprinting: Ofusca 18+ sinais de sistema e hardware (Canvas, WebGL, AudioContext, fontes, fuso horário e mais) que poderiam identificá-lo.
• Remoção de rastros: Interrompe parâmetros de rastreamento, minimiza cabeçalhos Referer e evita vazamentos de cache.
• Reforçar a privacidade do navegador: Bloqueia cookies de terceiros e a API Topics e aplica o Global Privacy Control.

GARANTIA RIGOROSA DE PRIVACIDADE

• 100% código aberto: Nosso código está aberto para qualquer pessoa examinar e verificar.
• Zero dados coletados: Não registramos, rastreamos nem vendemos (e nunca o faremos) a sua atividade de navegação ou informações pessoais.
• Zero telemetria: Nenhum Google Analytics ou outro rastreador está embutido na extensão ou no site.

Privacy Magic está em desenvolvimento ativo. Feedback ou dúvidas? Escreva-nos para contact@littletechllc.com.

SOBRE O AUTOR

Privacy Magic é criado por Arthur Edelstein, engenheiro de software dedicado a software de código aberto que defende a privacidade na web. Trabalhou em equipas de privacidade de três navegadores web diferentes e contribuiu para o desenvolvimento de várias inovações importantes na privacidade dos navegadores. É também o criador do PrivacyTests.org, uma iniciativa de código aberto que testa navegadores web em busca de fugas de privacidade.

ESPECIFICAÇÕES TÉCNICAS

- Bloqueia anúncios, rastreadores e incómodos
- Protege informações do sistema (ofusca 18+ sinais de sistema e hardware usados para fingerprinting)
- Remove rastos de rastreamento
  · Fugas de cache
  · Nome da janela
  · Parâmetros de rastreamento
  · Política de referência
- Reforça elementos web
  · Iframes
  · Service Workers
  · Shared Storage
  · Shared Workers
  · Web Workers
- Envia o sinal Global Privacy Control
- Desativa funcionalidades do navegador que revelam dados
  · Auditoria de hiperligações
  · Cookies de terceiros
  · WebRTC UDP sem proxy
- Desativa serviços na nuvem invasivos
  · Páginas de erro alternativas
  · Relatório alargado de navegação segura
  · Serviço ortográfico
  · Sugestões de pesquisa
- Desativa APIs de segmentação de anúncios
  · Medição de anúncios API
  · Protected Audience API
  · Topics API
- Ajuda-o a atualizar as definições do Chrome para mais privacidade
  · Desative a sincronização do histórico com os servidores da Google
  · Desative a telemetria de experiência do utilizador
  · Desative a telemetria de pesquisa e navegação
